1 · 現状の課題

プロっぽく見えない理由と、使いにくさの原因

エミュレーター（Pixel 7 / API 36）で全画面を確認し、XAMLとViewModelを読んだうえでの所見です。「見た目」と「使い勝手」の問題は、多くが同じ原因から来ています。

観察したことなぜ問題か提案での対応重要度
ステータスバー・ボタン・タブがすべてMAUIテンプレートの紫 #512BD4どのサンプルアプリとも同じ色で、アプリ固有の印象が残りません。パスポートの紺と入国スタンプの赤を軸にした配色トークンに置き換えます。高
画面ごとに見た目の言語が違う（スタンプ風、クリーム色のタイル、標準フォーム、地図）同じアプリの画面に見えず、つぎはぎの印象になります。紙・インク・スタンプという素材で全画面を統一します。高
色の直書き（AntiqueWhite / Red / DodgerBlue / #1E50A2 など）ダークモードで背景と文字がかみ合わず、色の変更も一括でできません。色はすべて Colors.xaml のトークン経由にし、ページからは名前で参照します。高
「ボード」タブの中に「国旗ボード」と「カスタムボード」が上タブで同居し、カスタムボードはボードが0件だと消える何がどこにあるのか予測できません。タブが出たり消えたりするのも混乱の元です。「コレクション」タブにまとめ、国・地域・カスタムボードを同じカードの並びで見せます。高
ボードのインポートが、地図画面のフィルター横にある「＋」の文字機能の存在に気付けません。インポートは地図ではなくコレクションの操作です。コレクション画面の「ボードを追加」カードに移します。高
削除・リセットは情報ウィンドウの長押し、地点指定は地図の長押し見えない操作なので、説明を読まないと使えません。誤操作も起きやすくなります。ピンを選ぶと下からシートが出て、「チェックイン」「経路」「削除」をボタンで並べます。中
画面上部の説明文（「現在地を確認して下のボタンを押してください」）UIが自分で説明できていないサインです。画面の一等地を文章が占めています。主ボタンのラベルと状態で伝え、説明文はなくします。中
フォントが4種類（Open Sans、Jerseyclub Grunge、craftmincho、Kiwi Maru）で役割が決まっていない文字の強弱に一貫性がなく、日本語は端末任せのフォールバックになります。UI用・タイル見出し用・スタンプ用の3役に整理します。中
設定画面：右寄せの大きな紫ボタン、赤字の注意書きすべてが同じ強さで主張し、どれが重要かわかりません。リスト形式の設定行にし、危険な操作だけ色を変えます。中
Android標準の下線付きPicker（国の選択、ボードの選択）未完成の画面に見えます。タップできることも伝わりにくいです。枠付きのセレクターかチップに置き換えます（今回のピンフィルターと同じ形）。中
2 · デザインの方向性

コンセプト「旅券と入国スタンプ」

アプリ名どおり、旅先で旗やスタンプを集めるラリーです。そこで、手元のパスポートを模した世界観に統一します。画面の地は紙、構造は表紙の紺、達成の瞬間はスタンプの赤、という役割分担です。赤は「記録する」「チェックインする」ときだけに使い、画面のどこに目を向ければよいかを色で伝えます。

Passport Navy#1F3A68主要色。アプリバー、選択状態、リンク
Stamp Red#C8402F行動の色。チェックイン、記録、訪問済み
Crest Gold#B58A2E実績・初訪問の演出にだけ使う
Visa Paper#FBF8F1画面の地。現在のAntiqueWhiteを置き換え
Ink#1B2233本文と枠線。純粋な黒は使わない
Success#2F7D5B状態表示専用（達成、同期完了）

文字の役割を3つに絞る

UI
Noto Sans JP — 地図・設定・ボタン。英日どちらも同じ字面
タイル見出し
Kiwi Maru — 伊勢神宮・鹿島神宮
スタンプ
22 SEP 2026 ARRIVAL

スタンプは今のJerseyclub Grunge（欧文）とcraftmincho（和文）をそのまま使います。上の見本は代替フォントです。Open Sansは日本語を持たないのでUIからは外します。

形と余白のルール

  • 余白は4 / 8 / 12 / 16 / 24の5段階だけを使う
  • 角丸はボタン・入力欄が10、シートとカードが16。スタンプは角を立てたまま
  • 影はシートと浮いているボタンだけに付ける。カードは線で区切る
  • タップできる要素は最低44pt。▲▼ボタンもこの大きさを守る
  • ダークモードは紺を地に、紙色を文字色に反転させる
3 · 情報設計

タブを「何をしに開くか」で分ける

いまのタブは画面の種類で分かれていて、カスタムボードのように同じ目的の機能が2か所に散っています。利用者の目的、つまり「記録を眺める」「現地で記録する」「集めているものを見る」で分け直します。

現在 4タブ＋上タブ

  • Bannerパスポート画像と到着スタンプ一覧。国フィルター
  • Boards上タブで「国旗ボード」と「カスタムボード」。カスタムは0件だと非表示
  • Location地図、ピンフィルター、ボードのインポート（＋）、現在地取得／チェックイン
  • Settings居住国、購読、APIキー、バックアップ、復元

提案 4タブ・常に同じ

  • パスポート表紙、訪問国数・地域数・チェックイン数、最近のスタンプ。到着スタンプ一覧へ
  • マップフィルターチップ、「ここを記録」ボタン、選択したピンの詳細シート
  • コレクション国・地域・各カスタムボードを進捗付きカードで。追加・並べ替え・削除もここ
  • 設定リスト形式。購読、データ（バックアップ・復元）、詳細設定（APIキー）

5 · アイコンとスプラッシュ

今のモチーフのまま、描き方を整える

アイコンの「赤いパスポート・地球・ピン・金の帯」と、スプラッシュの「旗を立てた地球・ピン・弧」は変えません。構図も色の組み合わせもそのままです。変えるのは描き方です。ビットマップをトレースした線を図形で描き直し、背景・色・光の当たり方を2つのあいだでそろえます。

小さいサイズでの見え方

通知や設定画面の24pxでも、赤い手帳と地球の形は判別できます。金の細い線は小さいサイズでは見えなくなりますが、形の判別には影響しません。

エミュレーターでの確認（Pixel 7 / Android 16）

提案のSVGを一時的にアプリへ組み込み、MAUIのビルドでPNGに変換したうえで実機表示を撮影しました。確認後、アプリの素材は元に戻しています。

組み込み方

素材はdocs/design/assets/にあります。下の3ファイルをResourcesへコピーし、FlagsRally.csprojを書き換えるだけで差し替えられます。Androidではこの設定でビルドと表示を確認済みです。iOSは未確認です。

  • スプラッシュの背景色を変えると、その後に一瞬出るアプリ本体の背景（今はテンプレートの紫）との差が目立ちます。Platforms/Android/Resources/values/colors.xmlのcolorPrimaryも紺にそろえると、起動がひと続きに見えます。
  • Android 12以降のスプラッシュはOSが拡大表示するため、わずかに柔らかく見えます。気になる場合はBaseSizeを大きくして比べます。
  • ストア用の512pxアイコンも同じ2枚のSVGを重ねて書き出します。Android 13のテーマアイコン（単色）に対応するなら、パスポートの輪郭だけの単色版を追加します。
6 · 使いやすさの改善

見た目以外で効く変更

迷わせない

  • カスタムボードが0件でもタブを消さない。空の状態で「ボードを追加」と説明を出す
  • 主ボタンは画面ごとに1つ。マップでは「ここを記録」か「チェックイン」のどちらか
  • 隠れたジェスチャー（長押し）は残しつつ、同じ操作を必ずボタンでも用意する
  • フィルターは今回のポップアップを、地図上のチップ（横スクロール）に発展させる

結果を伝える

  • チェックイン成功時はスタンプを押す演出と軽い振動。初訪問だけ金色を使う
  • 「近くにいません」のエラーには、あと何mかと「経路を表示」ボタンを添える
  • 削除後は数秒間「元に戻す」付きのトーストを出し、確認ダイアログを減らす
  • 読み込み中はスピナーの代わりに、カードの形をした仮表示（スケルトン）を出す

8 · 決めていただきたいこと

進める前の確認事項

配色の方向性はこの「紺・赤・紙」でよいか別案として、地図アプリらしい明るい緑系や、御朱印帳に寄せた和紙・朱色系も作れます。
ボトムシートにライブラリを使ってよいかMAUIには標準のボトムシートがありません。The49.Maui.BottomSheetなどを使うか、自前のオーバーレイで作るかを選びます。
タブ再編（段階3）まで進めるか既存ユーザーにとって場所が変わる変更です。段階1・2だけ先に出して反応を見る方法もあります。
アイコンとスプラッシュの背景を紺にするか今の黒を残すこともできます。紺にする場合は、アプリ本体の背景色（今の紫）も合わせて変えるのがおすすめです。
スタンプ用フォントを続投するかJerseyclub Grungeとcraftminchoはアプリの個性です。続投する前提で提案していますが、ライセンスの確認だけお願いします。
