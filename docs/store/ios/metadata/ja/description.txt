FlagsRally は、旅の記録をパスポートのスタンプにして集めるアプリです。

パスポート
国に着いたら記録すると、国旗と日付の入った「ARRIVAL」スタンプになります。到着の回数・国の数・地域の数がひと目でわかり、訪れた地域の旗も見られます。

世界地図
訪れた国や地域が、世界地図の上で塗り分けられます。

スタンプラリー
神社やお寺、マンホールカードなどのスタンプを集められます。公開されている一覧から追加するほか、自分で用意したファイルも読み込めます。その場所から 50 m 以内に来たら、地図からスタンプを押して記録します。

自分だけの地点
地図を長押しすると、好きな場所にピンを置いてスタンプを押せます。

データは端末の中に
アカウントは不要です。記録は端末に保存され、ファイルにバックアップして復元できます。

サブスクリプション
到着の記録は 5 件まで無料です。それ以上記録するには、月額または年額のサブスクリプション（新規登録は最初の 3 か月無料）に登録するか、設定でご自身の Google Maps API キーを入力してください。
お支払いは購入の確定時に Apple アカウントに請求されます。サブスクリプションは、現在の期間が終わる 24 時間前までに解約しない限り自動で更新されます。管理や解約は Apple アカウントの設定から行えます。
